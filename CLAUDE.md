# CLAUDE.md

## Project Overview

A modern replacement for `react-native-linear-gradient` with full New Architecture (Fabric) support. The original library has not been updated since September 6, 2023, and newer React Native versions no longer support the Old Architecture.

**Goal:** Fully implement all existing features of `react-native-linear-gradient` using Fabric.

## Tech Stack

- React Native New Architecture (Fabric)
- Native Components (Kotlin for Android, Swift/Objective-C for iOS)
- TypeScript

## Code Style

- Use recommended ESLint config for React Native (`@react-native/eslint-config`)
- Import statements must be sorted alphabetically
